# TRI-swim-strength

A mobile-friendly checklist app for the 45-minute resistance band dryland session (warm-up, 3-round main circuit, core finisher). Progress is tracked with tap-to-check boxes, saved locally in the browser, and the page is installable (Add to Home Screen) with offline support.

Open `index.html` directly, or visit the deployed GitHub Pages site (Settings &rarr; Pages, once the first deploy workflow run completes).

Built to match the Balance Tri Club design system: DM Sans/Outfit typography, navy/yellow/green palette, card-based layout.
