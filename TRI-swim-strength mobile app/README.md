# TRI-swim-strength

A mobile-friendly checklist app with two resistance band dryland sessions for swimmers:

- **Pre-swim primer** (20 minutes, about 12 of work). Wakes up the shoulder, lats and trunk before you get in. RPE 5 or below. You should finish fresher than you started.
- **Strength** (35 minutes, once a week, after an easy ride). Lat, triceps and trunk strength plus a pull-endurance finisher, aimed at holding stroke length late in a long swim rep.

Progress is tracked with tap-to-check set buttons and saved locally in the browser. The strength moves also take a band/load and last-set reps, which survive a reset so you can progress the band. The page is installable (Add to Home Screen) with offline support.

Why these moves, and the rule for deciding whether they work, is in the repo's `CLAUDE.md` (decision 49).

Open `index.html` directly, or visit the deployed GitHub Pages site (Settings &rarr; Pages, once the first deploy workflow run completes).

Built to match the Balance Tri Club design system: DM Sans/Outfit typography, navy/yellow/green palette, card-based layout.
