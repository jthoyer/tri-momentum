# TRI-run-strength

A mobile-friendly checklist app for an 18-minute single-leg strength circuit (glute bridge, single-leg RDL, reverse lunge, Copenhagen plank, jump squat &mdash; 4 rounds). Progress is tracked with tap-to-check round buttons, saved locally in the browser, and the page is installable (Add to Home Screen) with offline support.

Circuit structure sourced from [@londonfitnessguy](https://www.youtube.com/shorts/XD6MRzMI4Lw)'s "Strength training for runners" short.

Open `index.html` directly, or visit the deployed GitHub Pages site.

Built to match the Balance Tri Club design system: DM Sans/Outfit typography, navy/yellow/blue palette, card-based layout.
