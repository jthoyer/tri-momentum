# TRI-rehab-strength

A mobile-friendly checklist app for a soleus muscle strengthening rehab progression (seated calf raise, tiptoe walk, step calf raise &mdash; 3 exercises, 3 sets each). Progress is tracked with tap-to-check set buttons, saved locally in the browser, and the page is installable (Add to Home Screen) with offline support.

Exercise progression sourced from the club's Soleus Muscle Strengthening Cheat Sheet.

Open `index.html` directly, or visit the deployed GitHub Pages site.

Built to match the Balance Tri Club design system: DM Sans/Outfit typography, navy/yellow/blue palette, card-based layout.
